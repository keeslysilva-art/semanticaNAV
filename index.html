O que é a tag <nav>?

A tag <nav> (veio de navigation) é uma tag semântica do HTML5 usada para agrupar links de navegação da página.

Para que serve?

  • Organização: Identifica de forma clara onde fica o menu principal do site.
  • Acessibilidade: Leitores de tela conseguem avisar pessoas com deficiência visual que ali está a navegação do site.
  • SEO (Mecanismos de Busca): Motores de busca como o Google entendem melhor a estrutura do site e quais são os caminhos principais.

Estrutura Básica do <nav>

Dentro do <nav>, usamos uma lista não ordenada (<ul>), com itens de lista (<li>) e os links (<a>):

<nav>
    <ul>
        <li><a href="inicio.html">Início</a></li>
        <li><a href="sobre.html">Sobre</a></li>
        <li><a href="contato.html">Contato</a></li>
    </ul>
</nav>
