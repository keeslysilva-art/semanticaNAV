    O que é a tag <nav>?

    A tag <nav> é um elemento semântico introduzido na versão HTML5.

    A palavra nav vem de navigation (navegação). Ela é usada especificamente para agrupar e definir um bloco de links que direcionam o usuário para outras páginas do site ou para seções dentro da própria página.

    Antes do HTML5, os programadores usavam tags genéricas como <div id="menu">. Hoje em dia, usamos o <nav> para deixar o código com significado claro.
