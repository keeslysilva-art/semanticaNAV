• Início

    • Exemplos práticos do <nav>

    1. Menu Principal com Lista (Recomendado)

    Esta é a forma mais comum de criar menus:

    <nav>
    <ul>
        <li><a href="inicio.html">Início</a></li>
        <li><a href="sobre.html">Sobre Nós</a></li>
        <li><a href="contato.html">Contato</a></li>
    </ul>
</nav>

    2. Menu Simples Apenas com Links

    Também é permitido colocar os links direto dentro do <nav>:

    <nav>
    <a href="inicio.html">Início</a> |
    <a href="sobre.html">Sobre</a> |
    <a href="contato.html">Contato</a>
</nav>
